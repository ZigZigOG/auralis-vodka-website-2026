# AURALIS Vodka Website

Single-page static brand website for AURALIS Vodka.

## Files
- `index.html` — main website
- `style.css` — responsive visual styling
- `script.js` — age gate and mobile navigation
- `thanks.html` — Netlify form success page
- `netlify.toml` — Netlify publish configuration
- `images/` — supplied brand and photography assets

## Netlify
No build command is required. Publish directory is `.`.
